# 💠 Flow ERC20 Token

## 🧩 Project Overview
This project implements a basic *ERC20 token* deployed on the *Flow EVM Testnet*.  
The token follows the standard ERC20 specification, enabling users to *transfer tokens, **check balances, and **manage allowances* securely.

The goal of this project is to demonstrate how to deploy and interact with Ethereum-compatible smart contracts on the *Flow EVM*, leveraging its speed, low fees, and scalability.
